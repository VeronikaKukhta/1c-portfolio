
## 1. Главное отличие

| Характеристика | Процедура | Функция |
| :--- | :--- | :--- |
| **Что делает** | Выполняет действие | Вычисляет и возвращает результат |
| **Возвращает значение** | Нет (нельзя написать `Возврат`) | Да (обязательно есть `Возврат`) |
| **Как вызвать** | Просто по имени: `МояПроцедура();` | Можно сохранить результат: `Результат = МояФункция();` |
| **Ключевые слова** | `Процедура ... КонецПроцедуры` | `Функция ... КонецФункции` |

*Пример процедуры (просто делает):*
```bsl
Процедура ОчиститьПоля()
    Сообщить("Поля очищены");
КонецПроцедуры
```

*Пример функции (возвращает результат):*
```bsl
Функция Сложить(А, Б)
    Возврат А + Б;
КонецФункции
```

## 2. Параметры

Параметры — это переменные, которые мы передаем в блок кода в скобках. Они делают код универсальным.

*   **По значению:** Если передаешь число, строку или дату, то внутри процедуры меняется только копия. Оригинал снаружи не изменится.
*   **По ссылке:** Если передаешь объект (Массив, Структура, ТаблицаЗначений), то внутри меняется сам объект. Изменения будут видны снаружи.

*Пример передачи по ссылке:*
```bsl
Процедура ДобавитьЭлемент(МойМассив, Значение)
    МойМассив.Добавить(Значение); // Массив изменится снаружи!
КонецПроцедуры
```

## 3. Директива «Экспорт»

По умолчанию процедура или функция видна только внутри того модуля, где она написана. Если ты хочешь использовать её в другом модуле (например, из общего модуля), нужно добавить слово `Экспорт`.

*Пример:*
```bsl
// В Общем модуле "РаботаСФайлами"
Функция ПрочитатьФайл(Путь) Экспорт
    // ... код ...
    Возврат Содержимое;
КонецФункции

// В другом модуле мы можем её вызвать:
Результат = РаботаСФайлами.ПрочитатьФайл("C:\test.txt");
```

## 4. Вызов функции внутри функции

Это стандартная практика. Мы можем разбивать сложные вычисления на простые шаги.

*Пример:*
```bsl
Функция СложитьТриЧисла(А, Б, В)
    Промежуточный = Сложить(А, Б); // Вызываем функцию, написанную ранее
    Возврат Промежуточный + В;
КонецФункции
```

---

##  Топ-3 ошибки новичков

1. **Забыть `Возврат` в функции.** Если функция не возвращает значение, 1С выдаст ошибку при попытке присвоить её результат переменной.
2. **Пробел перед скобкой при вызове.** `Сложить (А, Б)` — не сработает. Только `Сложить(А, Б)`.
3. **Забыть `КонецЕсли` или `КонецПроцедуры`.** В 1С каждый открытый блок должен быть закрыт. Иначе код не скомпилируется.
