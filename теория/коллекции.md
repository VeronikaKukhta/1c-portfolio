
В 1С есть четыре основных типа коллекций для хранения данных. Они отличаются тем, как в них хранятся данные и как к ним обращаться.

## 1. Массив (`Массив`)
**Что это:** Упорядоченный список элементов. Как список покупок. Элементы нумеруются с нуля.
**Когда использовать:** Когда нужно просто перечислить однотипные данные (список ID, список названий).

**Основные методы:**
*   `Новый Массив` — создать.
*   `.Добавить(Значение)` — добавить элемент в конец.
*   `.Количество()` — узнать длину массива.
*   `Массив[0]` — обратиться по индексу (получить первый элемент).
*   `Для Каждого Элемент Из Массив Цикл` — перебрать все элементы.

**Пример:**
```bsl
Города = Новый Массив;
Города.Добавить("Минск");
Города.Добавить("Москва");

Сообщить(Города[0]); // Выведет "Минск"
```

---

## 2. Структура (`Структура`)
**Что это:** Набор пар «Ключ — Значение» (как словарь). Ключи задаются жестко в коде и не меняются.
**Когда использовать:** Когда нужно описать один объект с его свойствами (Имя, Возраст, Город).

**Основные методы:**
*   `Новый Структура` — создать.
*   `.Вставить("Ключ", Значение)` — добавить пару.
*   `Структура.Ключ` — получить значение по ключу.
*   `.Свойство("Ключ")` — проверить, есть ли такой ключ.

**Пример:**
```bsl
Человек = Новый Структура;
Человек.Вставить("Имя", "Иван");
Человек.Вставить("Возраст", 30);

Сообщить(Человек.Имя); // Выведет "Иван"
```

### 🔹 Вложенные структуры
В структуру можно вложить другую структуру или массив. Это используется для сложных данных (например, при разборе JSON).
**Пример:** `Студент.Успеваемость.Математика`

---

## 3. Соответствие (`Соответствие`)
**Что это:** Тоже словарь, но с двумя отличиями от структуры:
1. Ключом может быть **что угодно** (не только строка, но и число, дата, ссылка).
2. Ключи можно **добавлять динамически** в цикле.

**Когда использовать:** Когда ключи заранее неизвестны (например, подсчет слов в тексте).

**Основные методы:**
*   `Новый Соответствие` — создать.
*   `.Вставить("Ключ", Значение)` или `Соответствие["Ключ"] = Значение` — добавить.
*   `.Получить("Ключ")` — получить значение.
*   Обход: `Для Каждого Элемент Из Соответствие Цикл` (внутри доступны `.Ключ` и `.Значение`).

**Пример:**
```bsl
Склад = Новый Соответствие;
Склад.Вставить("Молоко", 10);
Склад.Вставить("Хлеб", 20);

Для Каждого Товар Из Склад Цикл
    Сообщить(Товар.Ключ + " - " + Товар.Значение);
КонецЦикла;
```

## 4. Таблица значений (`ТаблицаЗначений`)
**Что это:** Программный аналог таблицы Excel. У неё есть **колонки** (с типами данных) и **строки**.
**Когда использовать:** Когда нужно обработать табличные данные (результат запроса, загрузка из Excel, формирование отчета).

**Основные методы:**
*   `Новый ТаблицаЗначений` — создать.
*   `.Колонки.Добавить("Имя", Новый ОписаниеТипов("Строка"))` — создать колонку.
*   `.Добавить()` — добавить новую строку (возвращает объект строки).
*   `.Найти(Значение, "ИмяКолонки")` — найти строку по значению.
*   Обход: `Для Каждого Строка Из Таблица Цикл`.

**Пример:**
```bsl
Книги = Новый ТаблицаЗначений;
Книги.Колонки.Добавить("Название", Новый ОписаниеТипов("Строка"));
Книги.Колонки.Добавить("Год", Новый ОписаниеТипов("Число"));

Строка = Книги.Добавить();
Строка.Название = "Война и мир";
Строка.Год = 1869;

// Поиск
Найдено = Книги.Найти("Война и мир", "Название");
Если Найдено <> Неопределено Тогда
    Сообщить("Нашли книгу " + Найдено.Год);
КонецЕсли;
```

##  Топ-3 ошибки новичков при работе с коллекциями

1.  **Путаница между Структурой и Соответствием.** Если ключи известны заранее — бери структуру. Если ключи появляются в процессе работы (например, из базы) — бери соответствие.
2.  **Забыть `Новый` при создании.** Писать `Массив = Массив;` нельзя. Только `Массив = Новый Массив;`.
3.  **Ошибка в имени переменной в цикле.** Если массив называется `Города`, то писать нужно `Из Города`, а не `Из Город` (мы это уже проходили).
