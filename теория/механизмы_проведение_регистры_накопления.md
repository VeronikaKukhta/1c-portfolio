
# Конспект: Механизм проведения документов и регистры накопления

## 1. Зачем это нужно?
Документ сам по себе — это просто запись в журнале (он хранит данные в своих таблицах, например, в табличной части «Товары»). Чтобы система могла быстро считать остатки или обороты, документы должны **проводиться**. Проведение — это процесс, при котором документ записывает свои данные в **регистры**.

## 2. Регистры накопления (Ключевой тип)
Регистры накопления бывают двух видов:
*   **Остатки (РегистрОстатков):** хранит остаток на текущий момент (например, сколько товара на складе).
*   **Обороты (РегистрОборотов):** хранит только движения за период (например, выручка за месяц). *В 1С чаще используют «Остатки», так как они позволяют получить и обороты.*

**Структура регистра накопления (в конструкторе):**
*   **Измерения:** То, в разрезе чего мы считаем (Склад, Номенклатура, Контрагент).
*   **Ресурсы:** То, что мы считаем (Количество, Сумма).
*   **Реквизиты:** Дополнительная информация, не влияющая на расчеты (Комментарий, Номер документа).

## 3. Механизм проведения (События модуля объекта)
Когда пользователь нажимает кнопку «Провести», срабатывает обработчик в модуле объекта документа. Основной код пишется в процедуре **`ОбработкаПроведения`**.

**Важное правило:**
*   `ПередЗаписью` — используется для проверки заполнения (валидации) данных.
*   `ОбработкаПроведения` — используется **только** для записи движений в регистры. (Никаких проверок здесь быть не должно).

## 4. Как записать движения? (Код)
Для записи используются **наборы записей**. Алгоритм простой:
1. Создать набор записей: `Движения.ОстаткиТоваров.Добавить();`
2. Заполнить измерения: `Движение.Склад = Склад;`
3. Заполнить ресурсы: `Движение.Количество = Количество;`
4. Записать набор: `Движения.ОстаткиТоваров.Записать();`

*Пример кода в модуле документа (Расходная накладная):*
```bsl
Процедура ОбработкаПроведения(Отказ, Режим)
    // Очищаем старые движения, если документ перепроводят
    Движения.ОстаткиТоваров.Записывать = Истина;
    
    Для Каждого ТекСтрока Из Товары Цикл
        Движение = Движения.ОстаткиТоваров.Добавить();
        Движение.Период = Дата;
        Движение.Склад = Склад;
        Движение.Номенклатура = ТекСтрока.Номенклатура;
        Движение.Количество = -ТекСтрока.Количество; // Минус, т.к. это расход
        Движение.Сумма = -ТекСтрока.Сумма;
    КонецЦикла;
    
    Движения.Записать();
КонецПроцедуры
```

## 5. Виртуальные таблицы (Как читать остатки)
Регистры накопления не читаются напрямую. Для получения остатков используются **виртуальные таблицы** в запросах. В 1С это делается через параметры виртуальной таблицы:
*   `РегистрНакопления.ОстаткиТоваров.Остатки(&Период, Склад = &Склад)`

## 6. Оперативное проведение
Если в документе стоит галочка «Оперативное проведение», это значит, что при записи движений система проверяет **актуальность итогов** на момент проведения документа (чтобы не было отрицательных остатков). Если итоги устарели, 1С автоматически пересчитает их.
