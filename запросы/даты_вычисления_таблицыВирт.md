
## 1. Работа с датами в запросах

В 1С дата пишется в одинарных кавычках в формате `'ГГГГММДД'` (например, `'20260101'` — 1 января 2026 года).

###  Фильтрация по диапазону
Чтобы найти данные за период (год, месяц, неделю), используются два условия с операторами `>=` (больше или равно) и `<=` (меньше или равно), объединенные логическим `И`.

**Пример (весь 2025 год):**
```sql
ГДЕ
    ЗаказНаряд.Дата >= '20250101' 
    И ЗаказНаряд.Дата <= '20251231'
```

###  Функции дат
Если точные границы неизвестны (например, нужно найти все заказы за декабрь любого года), используются встроенные функции:
*   `ГОД(ПолеДаты)` — возвращает номер года (например, 2026).
*   `МЕСЯЦ(ПолеДаты)` — возвращает номер месяца (от 1 до 12).
*   `ДЕНЬ(ПолеДаты)` — возвращает день месяца.

**Пример (все заказы за декабрь):**
```sql
ГДЕ
    МЕСЯЦ(ЗаказНаряд.Дата) = 12
```

## 2. Логические операторы (И / ИЛИ)

В блоке `ГДЕ` можно комбинировать условия. Чтобы не запутаться в приоритетах, сложные условия берут в скобки.

**Пример (заказы за декабрь 2025 года ИЛИ январь 2025 года):**
```sql
ГДЕ
    (МЕСЯЦ(ЗаказНаряд.Дата) = 12 ИЛИ МЕСЯЦ(ЗаказНаряд.Дата) = 1)
    И ГОД(ЗаказНаряд.Дата) = 2025
```

## 3. Вычисляемые поля и приведение типов

В блоке `ВЫБРАТЬ` можно создавать новые поля, используя математические операторы (`+`, `-`, `*`, `/`).

###  Математика
**Пример (цена со скидкой 10%):**
```sql
ВЫБРАТЬ
    Услуги.Цена * 0.9 КАК ЦенаСоСкидкой
```

###  Фильтрация по вычисляемому полю
В 1С **нельзя** использовать псевдоним вычисляемого поля в блоке `ГДЕ`. Платформа сначала фильтрует данные, а потом вычисляет новые поля.
Чтобы отфильтровать по вычисляемому полю, нужно либо продублировать выражение в `ГДЕ`, либо использовать блок `ИМЕЮЩИЕ`.

**Пример (через ИМЕЮЩИЕ):**
```sql
ВЫБРАТЬ
    Услуги.Наименование,
    Услуги.Цена * 0.9 КАК ЦенаСоСкидкой
ИЗ
    Справочник.Услуги КАК Услуги
ИМЕЮЩИЕ
    ЦенаСоСкидкой > 500
```

###  Функция ВЫРАЗИТЬ
Используется для изменения типа данных (например, превратить число в строку или наоборот). Часто нужна при объединении таблиц, где типы полей не совпадают.
**Пример:** `ВЫРАЗИТЬ(ЗаказНаряд.Дата КАК СТРОКА(10))`

## 4. Объединение таблиц (ОБЪЕДИНИТЬ ВСЕ)

Позволяет собрать данные из двух разных таблиц в один список.
**Главное правило:** количество колонок и их типы в верхней и нижней частях запроса должны совпадать.

**Пример (список всех контрагентов):**
```sql
ВЫБРАТЬ
    Клиенты.Наименование КАК Контрагент
ИЗ
    Справочник.Клиенты КАК Клиенты
ОБЪЕДИНИТЬ ВСЕ
ВЫБРАТЬ
    Поставщики.Наименование
ИЗ
    Справочник.Поставщики КАК Поставщики
```

## 5. Итоги (ИТОГИ)

Блок `ИТОГИ` позволяет выводить промежуточные результаты (например, общую сумму по всей таблице).
*   `ПО ОБЩИЕ` — означает, что итог нужно посчитать по всей таблице целиком (общий итог).
*   Синтаксис: ставится в самом конце запроса.

**Пример (общая сумма всех работ):**
```sql
ВЫБРАТЬ
    ЗаказНаряд.Работы.Услуга.Наименование,
    СУММА(ЗаказНаряд.Работы.Сумма) КАК Сумма
ИЗ
    Документ.ЗаказНаряд КАК ЗаказНаряд
СГРУППИРОВАТЬ ПО
    ЗаказНаряд.Работы.Услуга.Наименование

ИТОГИ СУММА(Сумма) ПО ОБЩИЕ
```

## 6. Виртуальные таблицы (Остатки и Обороты)

Это готовые таблицы, которые 1С рассчитывает сама на основе движений регистров.

###  Остатки
Показывают, сколько товара есть на складе **прямо сейчас**.
*   Обращение: `РегистрНакопления.ИмяРегистра.Остатки`.
*   К имени ресурса добавляется суффикс **`Остаток`** (например, `КоличествоОстаток`).
*   Можно передавать параметр даты в скобках: `.Остатки(&ДатаОстатка)`.

**Пример:**
```sql
ВЫБРАТЬ
    Остатки.Запчасть.Наименование,
    Остатки.КоличествоОстаток
ИЗ
    РегистрНакопления.ЗапчастиНаСкладе.Остатки КАК Остатки
ГДЕ
    Остатки.КоличествоОстаток < 10
```

###  Обороты
Показывают, **что происходило** за период (сколько пришло и сколько ушло).
*   Обращение: `РегистрНакопления.ИмяРегистра.Обороты`.
*   К имени ресурса добавляется суффикс **`Оборот`** (например, `КоличествоОборот`).
*   Есть поля `КоличествоПриход` и `КоличествоРасход`.

**Пример:**
```sql
ВЫБРАТЬ
    Обороты.Запчасть.Наименование,
    Обороты.КоличествоОборот
ИЗ
    РегистрНакопления.ЗапчастиНаСкладе.Обороты КАК Обороты
ГДЕ
    Обороты.КоличествоОборот > 100
```
