### 1. Общая структура запроса
Любой запрос всегда строится в строго определенном порядке (как матрешка):
```sql
ВЫБРАТЬ
    <Поля и вычисляемые функции>
ИЗ
    <Источник данных> КАК <Псевдоним>
[ЛЕВОЕ СОЕДИНЕНИЕ <Источник2> КАК <Псевдоним2> ПО <Условие связи>]
ГДЕ
    <Условия отбора (фильтрация строк)>
СГРУППИРОВАТЬ ПО
    <Поля для группировки>
УПОРЯДОЧИТЬ ПО
    <Поля для сортировки> [УБЫВ]
```
*Квадратные скобки `[]` означают, что эта часть необязательная.*

---

### 2. Основные блоки и примеры

####  Выборка (`ВЫБРАТЬ` — `ИЗ`)
Это основа. Мы просто берем данные из таблиц.
*   **Обращение к полям справочника:** `Справочник.Товары` КАК `Товары` (пишем `Товары.Наименование`).
*   **Обращение к шапке документа:** `Документ.Продажа` КАК `Продажа` (пишем `Продажа.Клиент`).
*   **Обращение к табличной части документа:** `Продажа.СписокТоваров.Товар.Наименование` (именно так, через точку от псевдонима документа).
*   **Звездочка:** `Товары.*` — выбирает все поля таблицы (на практике использовать не рекомендуется, лучше перечислять поля явно для надежности).

**Пример:**
```sql
ВЫБРАТЬ
    Автомобили.ГосНомер,
    Автомобили.Пробег
ИЗ
    Справочник.Автомобили КАК Автомобили
```

#### Фильтрация (`ГДЕ`)
Позволяет отсеять лишние строки. Работает со строками, числами, датами.
*   **Равенство:** `ГДЕ Автомобили.Пробег = 50000`
*   **Больше/меньше:** `ГДЕ Автомобили.Пробег < 50000`
*   **Больше или равно:** `ГДЕ Работы.Количество >= 2`
*   **Строка:** `ГДЕ Клиенты.Город = 'Минск'` (строки всегда в одинарных кавычках).

**Пример:**
```sql
ВЫБРАТЬ
    Услуги.Наименование,
    Услуги.Цена
ИЗ
    Справочник.Услуги КАК Услуги
ГДЕ
    Услуги.Цена > 1000
```

####  Сортировка (`УПОРЯДОЧИТЬ ПО`)
Ставится в самом конце. По умолчанию (если не указать) сортирует по возрастанию. Чтобы по убыванию — добавляем слово `УБЫВ`.
**Пример:**
```sql
УПОРЯДОЧИТЬ ПО
    Услуги.Цена УБЫВ
```

####  Агрегация и Группировка (`СУММА`, `КОЛИЧЕСТВО` + `СГРУППИРОВАТЬ ПО`)
*Железное правило:* Если ты используешь функцию (например, `СУММА`), все остальные поля в `ВЫБРАТЬ` должны быть перечислены в `СГРУППИРОВАТЬ ПО`.
*   `СУММА(ЗаказНаряд.Работы.Сумма) КАК ОбщаяВыручка` — суммирует числа.
*   `КОЛИЧЕСТВО(ЗаказНаряд.Ссылка) КАК ВсегоЗаказов` — считает штуки.

**Пример:**
```sql
ВЫБРАТЬ
    Автомобили.ГосНомер,
    СУММА(ЗаказНаряд.Работы.Сумма) КАК ОбщаяВыручка
ИЗ ...
СГРУППИРОВАТЬ ПО
    Автомобили.ГосНомер
```

####  Соединение таблиц (`ЛЕВОЕ СОЕДИНЕНИЕ` ... `ПО`)
Берет все строки из левой таблицы и подтягивает данные из правой. Если совпадений нет — в полях правой таблицы будет `NULL` (пусто).
*   **Главное правило:** Соединяем по ключевым полям (например, `Ссылка` справочника = реквизит-ссылка в документе).

**Пример:**
```sql
ИЗ
    Справочник.Автомобили КАК Автомобили
    ЛЕВОЕ СОЕДИНЕНИЕ Документ.ЗаказНаряд КАК ЗаказНаряд
    ПО Автомобили.Ссылка = ЗаказНаряд.Автомобиль
```
