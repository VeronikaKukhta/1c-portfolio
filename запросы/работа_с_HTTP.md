
## 1. Зачем нужны HTTP-запросы?
1С не существует в вакууме. Ей часто нужно общаться с внешним миром: получать курсы валют, отправлять заказы в службы доставки, проверять погоду или статус контрагента. Для этого используется протокол HTTP (и его защищенная версия HTTPS).

## 2. Три кита HTTP в 1С
Работа с HTTP всегда состоит из трех шагов:
1. **`HTTPСоединение`** — устанавливаем «дорогу» до сервера.
2. **`HTTPЗапрос`** — формируем «письмо» (что именно мы хотим получить).
3. **`HTTPОтвет`** — получаем «посылку» с данными обратно.

## 3. Пример: Получаем погоду для Минска

Сервис **Open-Meteo** — бесплатный, не требует ключей API. Он принимает координаты (широту и долготу) и возвращает JSON с температурой и ветром.
*   Координаты Минска: Широта `53.9`, Долгота `27.5667`.
*   Адрес API: `https://api.open-meteo.com/v1/forecast`
*   Параметры: `?latitude=53.9&longitude=27.5667&current=temperature_2m,wind_speed_10m`

### Шаг 1. Установка соединения
Для HTTPS обязателен объект `ЗащищенноеСоединениеOpenSSL`. Он шифрует данные.
```bsl
// Создаем соединение. Порт 443 — стандартный для HTTPS
Соединение = Новый HTTPСоединение(
    "api.open-meteo.com", // Сервер
    443,                  // Порт
    , , , ,               // Пропускаем промежуточные параметры (логин, пароль и т.д.)
    Новый ЗащищенноеСоединениеOpenSSL() // Обязательно для безопасного соединения
);
```

### Шаг 2. Формирование запроса
В запросе передаем путь и параметры. Если параметров много, строку можно собрать через конкатенацию (`+`) или использовать `СтрШаблон`.
```bsl
// Формируем строку пути с параметрами
Путь = "/v1/forecast?latitude=53.9&longitude=27.5667&current=temperature_2m,wind_speed_10m";

// Создаем запрос
Запрос = Новый HTTPЗапрос(Путь);
```

### Шаг 3. Отправка и проверка ответа
Метод `Получить()` отправляет запрос. Сервер возвращает код состояния (200 — успех).
```bsl
// Отправляем запрос и получаем ответ
Ответ = Соединение.Получить(Запрос);

// Проверяем, что сервер ответил успешно
Если Ответ.КодСостояния <> 200 Тогда
    Сообщить("Ошибка сервера: " + Ответ.КодСостояния);
    Возврат; // Прерываем выполнение, если ошибка
КонецЕсли;
```

### Шаг 4. Извлечение текста (тела) ответа
Данные приходят в виде текста (формат JSON).
```bsl
// Достаем текст из ответа
ТелоОтвета = Ответ.ПолучитьТелоКакСтроку();
```

### Шаг 5. Разбор JSON
Превращаем текст в структуру, с которой умеет работать 1С.
```bsl
// Создаем объект для чтения
ЧтениеJSON = Новый ЧтениеJSON;
ЧтениеJSON.УстановитьСтроку(ТелоОтвета); // Указываем источник

// Читаем в структуру. Истина = используем структуры вместо соответствий
Данные = ПрочитатьJSON(ЧтениеJSON, Истина);

// Закрываем чтение (освобождаем память)
ЧтениеJSON.Закрыть();
```

### Шаг 6. Достаем нужные данные
Ответ от Open-Meteo устроен так: в корне лежит структура, внутри которой есть вложенная структура `current` (текущая погода), а в ней — поля `temperature_2m` и `wind_speed_10m`.
```bsl
// Проверяем, есть ли в ответе блок "current"
Если Данные.Свойство("current") Тогда
    // Обращаемся к вложенным полям через точку
    Температура = Данные.current.temperature_2m;
    Ветер = Данные.current.wind_speed_10m;
    
    Сообщить("В Минске сейчас " + Температура + " °C, ветер " + Ветер + " км/ч");
Иначе
    Сообщить("В ответе нет данных о текущей погоде");
КонецЕсли;
```

## 4. Полезные приемы и правила

###  Форматирование чисел для URL
Если координаты содержат много знаков после запятой, их нужно приводить к нужному виду. В 1С для этого используется функция `Формат()` с параметрами `ЧДЦ` (число десятичных) и `ЧРД` (разделитель дробной части — для URL нужна точка).
```bsl
ШиротаСтрокой = Формат(53.9000, "ЧДЦ=6; ЧРД=."); // Получим "53.900000"
```

###  Кодирование строк (URL-кодирование)
Если ты передаешь в URL русские буквы (например, название города), их нужно закодировать. В 1С для этого есть метод `КодироватьСтроку()`.
```bsl
Город = "Минск";
ГородВURL = КодироватьСтроку(Город, СпособКодированияСтроки.КодировкаURL);
// Результат: "%D0%9C%D0%B8%D0%BD%D1%81%D0%BA"
```

###  Обработка ошибок сети
Если интернет пропал, метод `Получить()` вызовет исключение и программа «упадет». Чтобы этого избежать, используем конструкцию `Попытка...Исключение`.
```bsl
Попытка
    Ответ = Соединение.Получить(Запрос);
Исключение
    Сообщить("Не удалось подключиться к серверу. Проверьте интернет.");
    Возврат;
КонецПопытки;
```

##  Топ-3 ошибки при работе с HTTP

1. **Забыть про `ЗащищенноеСоединениеOpenSSL`**. Без него 1С не сможет подключиться к современным сайтам по HTTPS (выдаст ошибку про SSL).
2. **Использовать метод не у того объекта**. Метод `Получить()` есть у `Соединения`, а не у `Запроса`. Правильно: `Ответ = Соединение.Получить(Запрос);`.
3. **Неправильный разбор JSON**. Если сервер вернул массив (начинается с `[`), то нужно использовать цикл `Для Каждого`. Если объект (начинается с `{`) — обращаться к полям через точку.
